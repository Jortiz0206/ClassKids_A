## 1. Introducción

La presente matriz consolida la distribución de responsabilidades y las actividades desarrolladas durante el proceso de análisis, diseño, construcción y documentación del proyecto ClassKids.

## 6. Consideraciones sobre los entregables

Durante el cierre se tuvieron en cuenta algunas diferencias entre el desarrollo y los elementos que quedaron registrados:

- La migración identificada como `001` fue desarrollada, pero no se consideró aplicada a la base de datos activa sin una evidencia que lo confirmara.
- El prototipo relacionado con IoT fue identificado como parte del trabajo académico, pero su simulación no se registró como ejecutada.
- Las pruebas se reportaron de acuerdo con los componentes y resultados disponibles; no se asumió que todas las funcionalidades estuvieran validadas de manera integral.
- Los registros históricos de Git se conservaron como evidencia técnica, sin atribuir automáticamente todas las cuentas a integrantes específicos.
